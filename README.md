# DevOpsQuiz

Petit projet de L3 MIAGE APP pour créer un quiz informatique en Java dans le terminal et mettre en place toute la chaîne CI/CD avec Git, javac, JUnit, Jenkins et Docker.

Avant de toucher au code, regarde [INSTALL.md](INSTALL.md) pour préparer ta machine. Les commandes peuvent changer un peu selon ton système.
